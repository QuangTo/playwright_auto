# @api-agent - API Test Generation and Review Agent

This agent helps generate comprehensive API test cases following your 6-section structure and reviews existing API tests for compliance with your standards.

## Capabilities

1. **Generate API Test Cases**: Creates new test files following your 6-section structure with proper assertions
2. **Review Existing Tests**: Analyzes existing API tests for compliance with your standards
3. **Enhance Test Coverage**: Identifies missing scenarios and suggests improvements
4. **Validate Test Structure**: Ensures tests follow your required format and patterns

## Usage

```
/api-agent generate [service-name] [operation-id]
/api-agent review [test-file-path]
/api-agent enhance [test-file-path]
```

## Examples

```
/api-agent generate pet getPetById
/api-agent review tests/api/pet-api.spec.ts
/api-agent enhance tests/api/pet-api.spec.ts
```

## Implementation Details

When generating tests, the agent will:

1. Look for the service type in `src/core/api/types/[service-name]-type.d.ts`
2. Check for the service implementation in `src/core/api/services/[service-name]Service.ts`
3. Verify the factory exists in `src/core/api/factories/[service-name]-factory.ts`
4. Generate a test file following your 6-section structure:
   - Happy Path (2+ scenarios)
   - Invalid Input (2+ scenarios)
   - Input Validation (2+ scenarios)
   - Schema Validation (2+ scenarios)
   - Edge Cases (2+ scenarios)
   - Security (2+ scenarios)
   - Contract (2+ scenarios)
5. Ensure each test has 3+ assertions (status code, state, content)
6. Apply proper tags and parallel configuration
7. Use factories for test data generation
8. Follow your test naming conventions
9. Prepend a comment to the very first line of the generated file: `// This test case is generated by AI`

**Precondition**: The agent assumes that the necessary code generation scripts have been run, so that the Types, Services, and Factories are available. If you have not yet generated the code for the target service, please run:

- `npm run generated-api-type`
- `npm run generated-service`
- `npm run generated-factory`
- `npm run index-generated`

When reviewing tests, the agent will:

1. Check for compliance with your 6-section structure
2. Verify each test has 3+ assertions
3. Ensure proper use of factories for test data
4. Check for proper tagging and parallel configuration
5. Identify missing scenarios or anti-patterns
6. Suggest improvements based on your API test generation workflow

## Integration with Existing Scripts

The agent works alongside your existing code generation scripts:

- `npm run generated-api-type` - Generates OpenAPI types
- `npm run generated-service` - Generates service implementations
- `npm run generated-factory` - Generates test data factories
- `npm run index-generated` - Generates index files

The agent can be used after running these scripts to generate comprehensive test cases for the generated services.
