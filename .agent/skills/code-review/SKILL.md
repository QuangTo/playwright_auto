# Code Review Skill

## Purpose
This skill assists in reviewing PRs and local changes to ensure they adhere to project standards and Playwright best practices.

## Instructions
1. Analyze the diff for architectural issues.
2. Check for brittle locators and non-web-first assertions.
3. Verify that new Page Objects follow the standard encapsulation rules.
4. Ensure no secret keys or sensitive data are committed.
