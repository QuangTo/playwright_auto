# Skill Template

This file serves as a template and guide for creating new skills within the `.agent/skills` directory.

## How to add a new skill

1. Create a new directory under `.agent/skills/` (e.g., `api-testing`).
2. Inside that directory, create a `SKILL.md` file.
3. Follow the YAML frontmatter format (name and description).
4. Provide detailed, actionable instructions for the AI on how to perform the specific task.

## Key Principles

- **Specific**: Focus on one area of expertise.
- **Actionable**: Provide steps or rules.
- **Contextual**: Use project-specific examples where relevant.
