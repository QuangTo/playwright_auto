# ⚡️ Power Prompts to Trigger Workflows

Copy and paste these prompts to get the best results from your AI agent.

## 1. 🧪 Generate a New API Test
**Use this when:** You need to test a new backend service endpoint.

> "I need to write a test for the `[SERVICE_NAME]` service. Please read `.antigravity/workflows/api-test-generation.md` first, then generate the spec file for the `[OPERATION]` operation."

## 2. 🖥️ Generate a New UI Test
**Use this when:** You need to test a frontend user flow.

> "I need to write a UI test for `[FEATURE_NAME]`. Please read `.antigravity/workflows/ui-test-generation.md` first. Follow the Page Object Model strictly."

## 3. 📄 Create a New Page Object
**Use this when:** You have a new page in your app and need the class definition.

> "Create a Page Object for `[PAGE_NAME]`. Please read `.antigravity/workflows/page-object-generation.md` first to ensure you use the correct encapsulation and locator strategies."

## 4. 🗺️ General Architecture Help
**Use this when:** You are lost or the AI asks "Where should I put this?"

> "Please review `.antigravity/workflows/code-map.md` to understand the project structure and tell me where this file belongs."
